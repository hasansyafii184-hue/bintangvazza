Cara Upload ke GitHub Pages

Panduan singkat bagi pemula untuk mempublikasikan website portofolio ini secara gratis.

1

Buat Repositori Baru

Masuk ke akun GitHub Anda, buat repository baru (misal dengan nama portofolio). Pastikan statusnya diatur ke Public.

2

Simpan File sebagai index.html

Salin kode lengkap halaman ini dan simpan dengan nama file persis index.html. Unggah file tersebut ke dalam repository GitHub Anda menggunakan tombol Add file > Upload files.

3

Aktifkan GitHub Pages

Buka tab Settings di repository Anda, cari menu Pages pada bagian kiri. Pilih branch main atau master, lalu klik Save. Website Anda kini online!
